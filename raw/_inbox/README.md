# _inbox/ — the drop zone

Put new sources here. Then tell the agent:

> **"Ingest the new source in raw/_inbox."**

The agent will read it, discuss the takeaways with you, update every wiki page it touches,
flag contradictions, update the index and log, then move the file into `../transcripts/` or
`../notes/`.

A meaningful source touches **8–15 pages**. If it only touched two, it was under-processed.
